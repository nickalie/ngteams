# is off).

# A tab separates the fields. Blank lines and lines that start with # are not read.
# pack <TAB> id <TAB> name <TAB> header file <TAB> flags (localized: the full picture's path names the locale;
#   meme: the meme paths and sizes)
# popular <TAB> sticker id <TAB> … : the stickers of the Popular pack, in order
# sticker <TAB> id <TAB> file <TAB> preview file (- for the file's own name) <TAB> name <TAB> keywords (- for none)
# caption <TAB> template file <TAB> font <TAB> colour <TAB> edge colour (- for none) <TAB> region (left top right
#   bottom, px of the template) <TAB> words: the caption of the sticker before it ("Edit sticker"), one block of words
#   that starts as its own words, or, with "-" for the region and the words, a meme's top and bottom lines. The
#   captions come from the web client's script of 2026-11-25 and the words from its en-us strings.
